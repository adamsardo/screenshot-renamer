# Changelog

## 0.1.0-preview.1

First native macOS developer preview.

- On-device Apple Intelligence naming with image input and Vision OCR context.
- PNG/JPEG/HEIC import, folder selection, drag/drop, image preview and editable descriptions.
- Description plus capture-date filenames and previewed collision suffixes.
- Exclusive no-overwrite rename, content/identity checks and durable recovery history.
- Persistent undo/redo, sandbox folder permissions and clear partial-failure handling.
- Apple silicon DMG packaging, safety-test CI and tagged GitHub prereleases.

This preview is ad-hoc signed and not notarised. AI naming remains experimental; review suggestions. Requires macOS 27.
